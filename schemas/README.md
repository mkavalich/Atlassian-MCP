# Schemas Directory

This directory contains auto-generated schema files used for validation.

## Files

### `tools.json`

Machine-readable schema of all MCP tools across all servers. Generated by:

```bash
npm run generate:tool-catalog
```

**Structure:**
```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "Atlassian MCP Tools Schema",
  "generated": "2026-01-02T...",
  "servers": {
    "jira-projects": {
      "description": "Projects, issues, dashboards, reporting",
      "toolCount": 38,
      "tools": {
        "jira_create_project": {
          "description": "Create a new Jira project",
          "type": "create",
          "parameters": ["name", "key", "projectTypeKey", "leadAccountId"],
          "annotations": { "destructiveHint": false, ... }
        }
      }
    }
  },
  "allTools": ["jira_create_project", "jira_get_project", ...]
}
```

**Usage:**
- Used by `validate-skills.js` to verify skill tool references
- Can be used by external tools for MCP discovery
- Regenerated automatically before `git push` via hook

## Do Not Edit

These files are auto-generated. Manual edits will be overwritten.

To update: modify the source tools in `servers/*/src/tools/`, then run `npm run generate:tool-catalog`.
